# BMI计算器

一个现代化的、用户友好的BMI（身体质量指数）计算器网页应用。

## 功能特点

- 简洁美观的用户界面
- 实时BMI计算
- 可视化的BMI分类指示器
- 根据BMI值提供个性化健康建议
- 支持性别、年龄、身高和体重输入
- 响应式设计，适配各种设备

## 使用方法

1. 在表单中输入您的个人信息：
   - 选择性别（男性/女性）
   - 输入身高（厘米）
   - 输入体重（公斤）
   - 输入年龄

2. 点击"计算BMI"按钮

3. 查看计算结果：
   - BMI数值
   - 体重分类
   - 健康建议
   - BMI分类图表指示

## BMI分类标准

- 体重过轻：BMI < 18.5
- 正常体重：BMI 18.5-24
- 超重：BMI 24-28
- 肥胖：BMI 28-35
- 重度肥胖：BMI > 35

## 技术栈

- HTML5
- CSS3
- JavaScript
- 响应式设计

## 本地运行

1. 克隆项目到本地
2. 使用浏览器打开index.html文件
3. 开始使用BMI计算器

## 注意事项

- BMI计算器仅供参考，不能替代专业医生的建议
- 请输入真实的身高和体重数据以获得准确结果
- 特殊人群（如运动员、孕妇等）的BMI标准可能有所不同
